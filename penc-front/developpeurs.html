Pourquoi Penc OTP ?

Une API pensée pour les entreprises sénégalaises et africaines : simple, sûre, facturée en FCFA.

💸

Moins cher que le SMS

Le code part par la messagerie Penc. Vous ne payez le SMS que lorsqu'il est vraiment nécessaire.

🛟

Secours SMS automatique

Si le client n'a pas Penc, le code part directement par SMS. S'il ne valide pas en 45 s, un SMS est envoyé.

🔒

Sécurisé

Codes chiffrés, expiration rapide, 5 essais maximum, limites anti-abus. Penc vérifie le code : vous ne le voyez jamais.

Tarifs simples

Crédit prépayé, rechargé par Wave. Aucun abonnement, aucun engagement.

Documentation de l'API

Deux appels suffisent : envoyer un code, puis le vérifier. Votre clé d'API se place dans l'en-tête Authorization. Ne l'utilisez que depuis votre serveur, jamais dans une appli mobile ou une page web.

1. Envoyer un code

POST https://api.penc-messagerie.com/api/otp/v1/send
Authorization: Bearer pk_live_votre_cle
Content-Type: application/json

{ "phone": "+221771234567", "ttl_minutes": 5, "channel": "auto" }
ChampDescription
phoneNuméro au format international (ex. +221771234567). Obligatoire.
ttl_minutesDurée de validité, de 2 à 10 minutes (5 par défaut).
channelauto (Penc puis secours SMS), penc (Penc uniquement) ou sms (SMS uniquement).
{ "id": "otp_3f9c…", "channel": "penc", "expires_in": 300, "cost": 10, "sms_fallback": true, "balance": 4990 }

2. Vérifier le code saisi par votre client

POST https://api.penc-messagerie.com/api/otp/v1/verify
Authorization: Bearer pk_live_votre_cle

{ "id": "otp_3f9c…", "code": "482915" }
{ "valid": true, "phone": "+221771234567", "channel": "penc" }
{ "valid": false, "reason": "incorrect", "tries_left": 3 }

Vous pouvez aussi vérifier avec "phone" au lieu de "id" : le dernier code en cours de ce numéro est utilisé. Raisons possibles : incorrect, expire, deja_utilise, trop_d_essais, introuvable.

3. Consulter votre solde

GET https://api.penc-messagerie.com/api/otp/v1/balance
Authorization: Bearer pk_live_votre_cle
